Amethyst Linux

Debian testing rolling, desktop-only, with GNOME 3 Revitalized.

Package repository

Amethyst Linux packages (the amethyst-* desktop and G3R stack) are served from this static site. Add it as a second APT source alongside Debian testing:

Types: deb
URIs: https://shadowcat782.github.io/amethyst-archive/
Suites: amethyst
Components: main
Signed-By: /usr/share/keyrings/amethyst-archive-keyring.gpg

Download the archive keyring: amethyst-archive-keyring.gpg, then save it as /usr/share/keyrings/amethyst-archive-keyring.gpg.

The repository is GPG-signed; InRelease verifies against the shipped keyring on every install or update.

About

Amethyst Linux is a rolling (testing) desktop distribution with GNOME 3 Revitalized — a forward-port of the GNOME 3.38 desktop stack to current Debian testing libraries. Firefox is the browser; Steam is preinstalled but removable. It ships as a live image for BIOS and UEFI hardware.
